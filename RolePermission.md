### Role & Permission

**1. Public Visitor**

* Tidak perlu login.
* Dapat mengakses seluruh halaman website.
* Dapat melihat informasi community dan event.
* Dapat melihat detail event.
* Dapat melakukan registrasi event.
* Dapat mengisi form membership.
* Dapat mengajukan collaboration.
* Dapat mengajukan sponsorship.
* Tidak dapat mengakses dashboard dan data internal.

**2. Admin**

* Wajib login.
* Dapat mengakses Admin Dashboard.
* Dapat menambah, mengedit, dan menghapus event.
* Dapat mengunggah poster dan dokumentasi event.
* Dapat melihat data registrasi event dan melakukan check-in peserta.
* Dapat melihat dan mengelola data membership.
* Dapat melihat pengajuan collaboration.
* Dapat melihat pengajuan sponsorship.
* Dapat mengelola aset website.
